# Today page 30-second parent-speed test

Scenario: routine state. A parent opens `/today`.

Expected within 30 seconds:
1. State current status from sticky strip.
2. Identify what is going well before risk list.
3. Identify single next action.
4. Find red-flag reference without scrolling through charts.

Scenario: alarm state. A parent opens `/today-alarm`.

Expected immediately:
1. Screen is visibly not the calm watercolor palette.
2. Sticky strip says urgent red flag active.
3. Recommendation says Because/evidence/action/urgency/confidence/source.
4. Source points to SRC-003 p.2 discharge instructions.
