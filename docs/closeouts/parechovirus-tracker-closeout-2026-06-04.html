What was built

A new /parechovirus page on the existing Child Health Dashboard that lets a parent log symptoms as they happen and runs a source-linked triage engine to surface issues at the right urgency (911 / urgent / today / soon / watch). Built in seven commits on v2-redesign.

Safety

  • All data stays local (no external services enabled by default, matching the rest of the dashboard's discipline)
  • Red-flag thresholds and rule source snippets are stored with the issue itself, not just rendered in the UI
  • UI explicitly says "This is a tracking tool, not a diagnosis" in the footer
  • 911 rules use the most conservative path - any seizure / apnea / bulging fontanelle / fever+lethargy combo escalates immediately
  • 6h dedupe cooldown prevents spamming duplicate issues for the same rule when re-logging
